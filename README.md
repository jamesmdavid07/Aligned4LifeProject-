# Aligned4LifeProject

A website for Aligned4Life — a ministry dedicated to helping people align their lives with God through biblical teaching, devotionals, and resources.

## Local Development

Run the site locally with:

```bash
npm install
npm run dev
```

## Deployment

This project is kept as a standard local Next.js project. Deploy it by pushing changes to GitHub and connecting that repository in Hostinger.

Set `NEXT_PUBLIC_SITE_URL` in Hostinger to the live site URL, for example `https://yourdomain.com`.

Build command:

```bash
npm run build
```

Start command, if Hostinger is running the Next.js app with Node:

```bash
npm run start
```
